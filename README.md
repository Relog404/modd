# Freddy Half Puker — исходный проект

В репозитории изначально был только собранный `freddypuker-1.0.0 (6).jar`, без редактируемых Java-файлов. Исходники и ресурсы восстановлены в `src/main`; здесь внесены изменения геймплея.

## Изменения

- При сне в обычном мире выполняется независимый бросок: **40% — особняк**, **40% — ровная поляна с симметричными деревьями**, **20% — обычный сон с пропуском ночи**.
- В особняке взгляд на глаз дольше 1,5 секунды накладывает слепоту и замедление. Через пять секунд появляется Фредди; обратный отсчёт игроку не показывается.
- На поляне Фредди начинает преследование сразу. В этом варианте после смерти от него игрок возвращается к точке появления в обычном мире.
- Базовая скорость Фредди выставлена в пять раз выше стандартного атрибута скорости игрока.
- Если Фредди убивает игрока в особняке, тот возрождается на небесной платформе. На ней есть могила с табличкой, именем игрока и датой. Падение с платформы переносит игрока в тот же измерительный мир сна и восстанавливает выбранную сцену.

## Сборка

Нужен JDK 21 и доступ к Forge Maven. Gradle 8.10.2 устанавливается автоматически при первом запуске Gradle Wrapper:

```sh
./build.sh
```

На Windows запусти `gradlew.bat build`. Собранный мод появится в `build/libs/`. Файл `freddypuker-1.0.0 (6).jar` в корне оставлен как исходный бинарный файл для сравнения; изменённый мод нужно собрать из исходников.
